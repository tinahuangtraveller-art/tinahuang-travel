# Conversation Starters

這 5 個貼到 Custom GPT 設定的「Conversation starters」欄位：

1. 我要寫一篇新攻略
2. 幫我把這段語音逐字稿整理成攻略
3. 幫我檢查我寫好的 markdown 是不是符合品牌規則
4. 我剛從某個地方回來，想寫住宿／景點／美食心得
5. 我想寫一篇純整理類的攻略（我沒親自去）

## 使用情境對照

| Starter | 用在什麼時候 |
|---|---|
| 我要寫一篇新攻略 | 從頭開始，GPT 會問你全部問題 |
| 整理語音逐字稿 | 旅行中錄了語音筆記，用 Whisper 轉文字後丟給 GPT |
| 檢查 markdown | 你自己寫了 draft，請 GPT 挑錯（禁用詞、結構、誠信揭露） |
| 住宿／景點／美食心得 | 快速啟動，GPT 會依類型問對應問題 |
| 純整理類 | 明確告訴 GPT 這是 researched 類型，避免它用「我覺得」等第一人稱 |
